# 数据模型与存储

本地资产库默认在 `data/assetgate/`。`ASSETGATE_STORAGE` 可指定独立的持久目录。`workspace.sqlite` 使用 SQLite WAL 和外键，目录里的唯一 ID 同时用于文件归档和追踪任务。旧的 `data/artpipe.sqlite` 继续服务历史工作台。

| 表 | 关系与记录 |
| --- | --- |
| assets | 资产名称、类型、创建时间、当前版本及其切换序号 |
| versions | 资产内单调编号、父版本、模型路径及 SHA256、格式、文件清单、原始上传哈希、预览与新鲜度 |
| runs | 来源版本、任务类型、参数、输入输出、节点状态、执行方式、错误、重试来源、生成版本和导出路径 |
| reports | 每次检查的规则版本、摘要、指标、规则明细，对应版本与任务 |
| processing_baselines | 每次处理实际复核的源版本快照，绑定生成版本与对应任务 |
| reviews | 审核人、时间、决定、备注，绑定精确的版本与检查报告 |

原始上传保留在首版目录。ZIP 同时保存原包和解包文件。模型和贴图都以相对路径记录。上传限制配置于 `configs/assetgate.yaml`，文件校验失败会撤回暂存结果。多模型 ZIP 可指定主模型，引用须落在包内。
