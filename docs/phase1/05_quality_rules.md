# QA 规则与证据

`configs/assetgate.yaml` 中的 `rules` 设置文件大小、三角面预算、非流形、退化、孤立几何、UV、贴图尺寸等阈值。更改规则后，在 `ruleset_version` 写入新版本，重启服务后发起新检查。规则结果包含规则 ID、状态、严重程度、实际值、预期值、证据和处理建议。

默认将非流形边、缺失 UV、缺失材质和 UV 越界记为提醒。缺少用于某项检查的数据时报告 `NOT_CHECKED`。缺失依赖、模型无法导入、三角面超预算和无有效几何可形成阻断项。边计数包含开口边界。退化面使用配置的局部面积容差，尺寸和包围盒以 Blender 世界坐标计算，顶点等计数基于导入后的网格数据。

阶段验证使用真实 OBJ 三角形，Blender 测得 1 个三角面、缺失 UV 警告并写出 GLB 预览。测试还覆盖可配置严重程度及导入失败时的未检查状态。
