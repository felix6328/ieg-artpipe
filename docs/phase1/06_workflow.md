# 任务、版本、审核与导出

上传后自动排队检查。Worker 通过 SQLite 事务领取任务，并持有存储目录级进程锁。服务重启时，未完成的任务回到队列；已请求取消的任务保留取消。运行中取消会停止 Blender 进程组，失败或取消的任务可用原参数新建重试记录。

处理流程先检查源文件，再逐一执行用户选择的变换、法线、Smart UV，最后写出所选格式并用 Blender 重新导入最终文件检查。任务详情保留各节点状态、参数和日志。生成版本可以在页面直接与该次处理保存的父版本 QA 快照对照。切回上游或分支变更后，废弃下游标记 `STALE`。任务排队期间若上游切换，结果保留供查看，但不会替换当前版本。

通过审核需要真实 Blender 检查记录且阻断项为零。每次决定关联所见报告的新鲜快照。导出、下载时再次核对审核。ZIP 包含 `model/` 下的最终模型和依赖、`manifest.json`（含逐文件 SHA256）、`qa_report.json`、`processing_history.json`、`version_info.json` 与 `review.json`。嵌入式贴图随模型文件一同导出。

已以真实 Blender 跑通 OBJ 应用变换、重算法线、Smart UV、转换 GLB、再导入、审批及 ZIP。Smart UV 后缺 UV 规则由警告变为通过。
