# 已知限制

- 真实引擎集成验证范围为 Blender 5.2.1 LTS 和本机 Chrome。Manifest 的引擎导入字段为 `NOT_CHECKED`，Unreal Engine 未进行导入验证。
- 工作台面向单机串行、受信任的本地用户。运行平台已覆盖 macOS，Linux 使用相同 POSIX 进程与文件锁逻辑，尚未跑本次真机验收。Windows 暂未接入。
- FBX 使用 Blender 已注册的 Python 导入器以限制外部图片读取。仅有原生 FBX 导入器的 Blender 构建会报告不支持该导入路径。
- 指标取自导入后的网格。格式转换可能因为顶点法线、UV 缝、三角化及 Blender 读写选项改变拓扑计数。包围盒和尺寸使用 Blender 场景单位。UV 越界与开口网格默认作为提示证据。
- 自动处理面向基本网格，复杂绑定、动画、材质图和专有格式特性需人工核对转换结果。Smart UV 修改所选版本的 UV 副本，需要审核。预览帧不提供动画播放。
- 工作台不会自动清理历史版本、任务日志或导出包。备份存储时先关闭服务，保留整个存储目录及 SQLite 文件。无 WebGL 2 的浏览器仍能查看检查、历史和导出页面。
- 既有 0 A.D. 研究报告随仓库交付。历史回放和部分目录页面的实时数据依赖 ArtPipe 原有的本地缓存准备步骤。
